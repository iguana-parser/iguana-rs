# iguana-runtime

The runtime library for parsers generated by
[Iguana](https://github.com/iguana-parser/iguana-rs). A generated parser
depends on this crate at the exact version it was generated with and moves to
a newer one by regeneration, so there is no reason to depend on it directly.
