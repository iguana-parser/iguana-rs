# iguana-runtime

`iguana-runtime` provides the GLL data structures and algorithms shared by
parsers generated by [Iguana](https://iguana-parser.org). Each generated parser
depends on the runtime version used during generation. Regenerate the parser to
move it to a newer runtime; applications should not add a direct dependency on
this crate.
