# iguana

A high-performance GLL parser generator. Iguana takes a grammar written in the
iggy grammar definition language and generates a complete Rust parser crate for it.
GLL accepts any context-free grammar, so ambiguity is detected and
explicitly reported. Disambiguation is declarative: the grammar states which
parse tree is intended, using constructs such as priorities, associativity,
and restrictions. To resolve ambiguities, the parser follows these declarations rather than
heuristics or the definition order of rules.

## Getting started

```bash
cargo install iguana --version 0.1.0-alpha

iguana new my-parser        # create a project with a starter grammar
cd my-parser
iguana generate             # generate the parser crate from the .iggy file
```

The generated crate contains the parser code: a library with typed parse-tree
accessors, and a CLI binary for parsing inputs. See the [getting started
guide](https://iguana-parser.org/docs/getting-started/) for a walkthrough, and
the [grammar definition](https://iguana-parser.org/docs/grammar-definition/)
reference for the iggy grammar definition language.
