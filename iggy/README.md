# iggy

The parser for the [iggy grammar definition language](https://iguana-parser.org/docs/grammar-definition/).
The parser itself is generated by
[iguana](https://github.com/iguana-parser/iguana-rs) from `iggy.iggy`. The iguana generator and the language
server use this crate to read grammars. End users never directly depend on this crate.

The package publishes on crates.io as `iguana-iggy`, since the name `iggy`
belongs to an unrelated project. The library target keeps the name `iggy`.
