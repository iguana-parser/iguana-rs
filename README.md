# Iguana

A GLL parser generator written in Rust.

## Project Structure

```
iguana-rs/
├── iguana/              # Parser generator + CLI
├── iguana-runtime/      # Runtime library for generated parsers
├── iggy/                # Generated parser for iggy grammar syntax
└── terrarium/           # Grammar debugging tool (Tauri app)
```

### Crates

| Crate | Description |
|-------|-------------|
| `iguana` | Parser generator CLI. Takes a grammar and generates a parser. |
| `iguana-runtime` | Runtime library that generated parsers link against. |
| `iggy` | Parser for the iggy grammar syntax, itself generated by iguana. |

### Dependency Graph

```
iguana-runtime  (standalone - no internal deps)
       ↑
     iggy  (depends on runtime)
       ↑
    iguana  (depends on runtime + iggy)
```

## Building

```bash
cargo build              # Build all crates
cargo build -p iguana    # Build just the generator
```

## Usage

```bash
# Initialize a new iggy project
cargo run -p iguana -- init --output ./my-parser

# Generate a parser from an iggy grammar file
cargo run -p iguana -- generate --grammar path/to/grammar.iggy --output ./my-parser

# Generate using the built-in iggy grammar (for bootstrapping)
cargo run -p iguana -- generate --output ./iggy
```

## Bootstrapping

Iggy (the grammar syntax) is defined in `iguana/src/main.rs` using a Rust DSL. The iggy parser is generated from this definition.

After modifying the grammar definition or generator code, regenerate the iggy parser:

```bash
./bootstrap.sh
```

This runs `cargo run -p iguana -- generate --output iggy` to regenerate the parser.

### Future: Self-hosting

Eventually, the iggy grammar will be defined in an `.iggy` file, and the bootstrap process will use the previous iggy parser to parse the new grammar definition (standard compiler bootstrap).

## Running the Iggy Parser

```bash
# Parse a file
cargo run -p iggy -- --start Grammar path/to/file.iggy

# List available nonterminals
cargo run -p iggy -- --list-nonterminals

# Generate SPPF visualization
cargo run -p iggy -- --start Grammar file.iggy --vis sppf
```

## Testing

```bash
cargo test
```

### Adding Grammar Tests

Grammar tests live in `tests/<grammar-name>/` with parse tree golden files for verification.

**Create a new grammar test:**

```bash
# Initialize test (creates grammar, generates parser, sets up test infrastructure)
cargo run -p iguana -- test init mygrammar

# Edit tests/mygrammar/mygrammar.iggy with your grammar rules
# Edit tests/mygrammar/tests.rs with test cases

# Regenerate parser after grammar changes
cargo run -p iguana -- generate --grammar tests/mygrammar/mygrammar.iggy --output tests/mygrammar

# Update golden files and run tests
REGENERATE=1 cargo test -p mygrammar
```

**Test commands:**

```bash
cargo run -p iguana -- test init <name>         # Create new grammar test
cargo run -p iguana -- test delete <name>       # Delete grammar test (alias: rm)
cargo run -p iguana -- test generate-all        # Regenerate all test parsers
```

**Test structure:**

```
tests/mygrammar/
├── mygrammar.iggy     # Grammar definition
├── tests.rs           # Test cases
├── parse_trees/       # Golden files (generated)
├── Cargo.toml
└── src/               # Generated parser
```

**Writing tests:**

```rust
use mygrammar::{parse, parse_tree::to_sexpr};
use iguana_runtime::testing::{check_golden_file, golden_path};

fn check(start_nonterminal: &str, input: &str, test_name: &str) {
    let tree = parse(input, start_nonterminal).expect("Parse failed");
    let actual = to_sexpr(tree.as_parse_tree_ref());
    check_golden_file(&actual, &golden_path(env!("CARGO_MANIFEST_DIR"), test_name));
}

#[test]
fn test_example() {
    check("StartMygrammar", "input text", "example");
}
```

Run with `REGENERATE=1` to create/update golden files.
