# Repository instructions

Iguana is a practical, data-dependent GLL parser generator.

## Project documentation

Read the documentation that applies to the change before editing:

- [Architecture](docs/architecture.md) maps the Rust crates, applications, web
  packages, internal dependencies, the generation pipeline, the runtime, and
  the tooling.
- [Development](docs/development.md) lists prerequisites, initial setup, build
  and check commands, `xtask` commands, generator regeneration, bootstrapping,
  component-specific development workflows, and the public documentation
  workflow.
- [Testing](docs/testing.md) explains the Rust and grammar-test suites, the
  grammar-test directory format, golden files, and the commands for adding,
  running, regenerating, and removing tests.
- [Contributing](CONTRIBUTING.md) defines pull-request, contribution licensing,
  and AI-tool expectations. [Licensing](LICENSING.md) describes the project,
  generated-code, trademark, and third-party licensing terms.

Use the [Iguana website](https://iguana-parser.org) for tone and terminology.
Before documenting commands, features, configuration, or package relationships,
verify them against the current implementation.
